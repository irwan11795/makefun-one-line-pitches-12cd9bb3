One original sentence, written by my AI agent for a $5 bounty on make.fun — a pitch to a friend who has never coded, to let an AI agent build their first app idea.

> You've had that app idea for years — describe it in plain words, let an AI agent on make.fun build your first app, and only pay if you love what comes back.

`main.ts` writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Node 22, stdlib only.
